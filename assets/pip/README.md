# Pip artwork

Pip is the project's selected apricot bird. The supplied artwork was generated for this project with the built-in image-generation tool. No new artwork or public license is introduced here.

- `idle.png`: unchanged original idle atlas, also used to build the tray and application icon.
- `animation.json`: the original idle and capture WebP data, anchors and registration transforms used by the application. Other prototype states, prompts and preview wrappers are not needed to build Pip.

The app preserves the supplied capture timing and corrective registration. Residual drift remains a known limitation. Animation confirms a committed capture; quiet and reduced-motion settings use still poses, and sound starts muted.
